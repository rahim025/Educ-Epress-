# Educ’Express

**Vos élèves à jour, sans détour.**

Educ’Express importe vos élèves sur Educmaster (Educ Master) à votre place : listes vérifiées, élèves à jour, option express sous 24 heures.

**Site officiel : https://rahim025.github.io/Educ-Epress-/**

## Comment ça marche

1. **Vous envoyez** vos listes d’élèves (Excel, PDF ou photo).
2. **Nous vérifions** les données : doublons, oublis, erreurs de saisie.
3. **Nous importons** sur Educmaster et confirmons la mise à jour.

## Nos garanties

- **Rapide** : option express sous 24 heures.
- **Fiable** : chaque liste est contrôlée avant l’import.
- **Confidentiel** : les données servent uniquement à l’import (voir la page de confidentialité du site).
