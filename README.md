## Publier sur GitHub Pages

1. Créer un dépôt public nommé `educ-express`.
2. Y envoyer les 4 fichiers (Add file, puis Upload files).
3. Settings, puis Pages : choisir la branche `main` et le dossier `/ (root)`.
4. Remplacer `VOTRE-NOM` par votre nom d’utilisateur GitHub dans `index.html`, `robots.txt`, `sitemap.xml` et ce README.
5. Ajouter le site dans Google Search Console et envoyer `sitemap.xml`.
